06  {explain} Now the bubble sort. The outer loop runs n minus one passes. The inner loop compares each pair of neighbours, and swaps them when the left one is bigger. Every swap increments our counter. After each pass the largest element has bubbled to the end, so the inner loop stops one position earlier each time.
07  {explain} Finally, print the sorted array and the swap count, with clear labels, exactly as the problem asks.

13  {emphatic} For the viva: bubble sort makes n minus one passes and, in the worst case, about n squared by two comparisons, so the time complexity is order n squared. The swap count depends on the input: four here.
