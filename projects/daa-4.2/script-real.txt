05  {explain} This is Unit Four, video two. | Today: decision versus optimisation problems, the formal definitions of P and NP, NP hard and NP complete, and the P versus NP question.
06  {explain} Defining these four classes, with the diagram, is a guaranteed exam question, | so stay till the end for the exam tips.
07  {explain} An optimisation problem asks for the best answer: | the shortest tour, the maximum profit, the fewest colours.
08  {explain} A decision problem asks only yes or no: | is there a tour of length at most k? Is there a packing with profit at least r? Can the graph be coloured with k colours?
09  {explain} The two are linked. If you can solve the decision version in polynomial time, you can solve the optimisation version too, | by asking the yes or no question for different values of k, a polynomial number of times.
10  {emphatic} That is why complexity theory talks about decision problems only. | Every class we define today is a class of decision problems.
11  {explain} The class P: all decision problems that a deterministic algorithm can solve in polynomial time. | Shortest path, minimum spanning tree, is this number prime: all in P.
12  {explain} The class NP: all decision problems that a non deterministic algorithm can solve in polynomial time. | Guess a candidate answer, verify it in polynomial time.
13  {explain} Hamiltonian cycle, the decision knapsack, graph colouring, satisfiability: all in NP. | The certificate, a cycle, a packing, a colouring, an assignment, can be checked fast.
14  {emphatic} Every problem in P is also in NP: a deterministic algorithm is just a non deterministic one that never uses Choice. | So P is a subset of NP.
15  {curious} The open question is the other direction. Is every problem in NP also in P? Nobody knows. | Most computer scientists believe P is not equal to NP, but there is no proof.
16  {explain} To define the hard classes we need one special problem: satisfiability. | Given a Boolean formula, is there an assignment of true and false to its variables that makes it true?
17  {explain} For example: x one or x two, and, not x one or x three. Setting x one true and x three true satisfies it. | With n variables there are two to the n assignments, but checking one is easy. So SAT is in NP.
18  {explain} Next, reducibility. Problem L one reduces to L two | if a deterministic polynomial time algorithm can turn any instance of L one into an instance of L two with the same yes or no answer.
19  {explain} So if L two can be solved in polynomial time, so can L one. L two is at least as hard as L one. | Reductions are the whole of the next video; today we only need the definition.
20  {emphatic} A problem L is NP hard if satisfiability reduces to L. | Equivalently: every problem in NP reduces to L. L is at least as hard as everything in NP.
21  {emphatic} A problem L is NP complete if it is NP hard and it is also in NP. | The hardest problems inside NP.
22  {explain} Why satisfiability? Cook's theorem, nineteen seventy one: satisfiability is in P if and only if P equals NP. | SAT was the first NP complete problem, and every other one is proved by a reduction from it.
23  {explain} NP complete problems: satisfiability, three SAT, Hamiltonian cycle, vertex cover, clique, graph colouring, the decision knapsack. | We will prove some of these in video four point four.
24  {explain} Some problems are NP hard but not NP complete, because they are not in NP. | The halting problem is one: no algorithm decides it at all, yet SAT reduces to it. And optimisation versions, like the shortest tour, are NP hard.
25  {explain} Here is the picture to draw in the exam. P inside NP. NP hard overlapping NP. | The overlap is NP complete. Outside NP sit the NP hard problems that are not NP complete.
26  {excited} If anyone ever finds a polynomial algorithm for one NP complete problem, then by the reductions every problem in NP has one, | and P equals NP. The whole picture collapses into one circle.
27  {warm} That is why it is a millennium prize problem: | one million dollars from the Clay Mathematics Institute, unclaimed since the year two thousand.
